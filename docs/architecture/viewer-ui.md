## UI / Docks (P1–P4)
- ✅ **NCI has one home** (UX stage 4a-3): the Interactions dock = collapsible "Options" (`NciOptionsWidget` in `nciwidget.*`: contact kinds, H-bond gate, colours, labels, live MD; drives the viewer directly) above the contact table (`NciWidget`, source selector). View ▸ NCI Options… opens it (`NciDock::expandOptions`). Colour helpers shared via `widgets/colorswatch.h`.
- ✅ **Tools section dissolved** (UX stage 4a-2): measure + bond tools are viewer-bar tools; walls, wall potential shells/force field, grab force vectors and dynamic bonds are in the Simulation dock's collapsible "Show in viewer" (`SimulationViewOptions`, `docks/simulationdock.*`); centre-on-load and mouse rotation in Edit ▸ Preferences; the docking preview in Build ▾.
- ✅ **Appearance dock** (`docks/appearancedock.*` holding `displaypanel.*` + `widgets/collapsiblesection.*`; right side, tabbed, closed by default): the *detailed* home for all viewer options: a flat Style group (mode, colours, sizes, labels, background) plus the Fragments/Bead-type groups when the structure has them, then one collapsed "Advanced" section with Material / Lighting / Effects (UX stage 4a-4; expand state + dock splitter persisted in `ui/displayPanel/*`, `ui/appearanceDock/splitter`). Frequent toggles (NCI, render style, colour scheme, labels, sizes, fit) also live in the **View menu**, the viewport right-click context menu and the viewer bar — all backed by ONE shared QAction set mirrored from viewer signals. The viewer is the single source of truth for live display state: the panel only reads (`syncFromViewer()`), the last session's settings are applied once at startup via `MoleculeViewer::applyDisplaySettings()` (saved on exit from `currentDisplaySettings()`), Reset applies `DisplaySettings{}`, looks set their own fields only. Viewer top bar (UX stage 2): [frame-nav + playback, only for trajectories] | tool selector View · Measure · Edit · Build (exclusive `QButtonGroup` over `setInteractionMode`; Build ▾ = fragments + bond tools) | NCI ▾ · H-bonds · H ▾ · Style ▾ (icon-only quick toggles) | Look ▾ (looks, save/delete, colour scheme, Details…) · Photo ▾. The quick buttons get MainWindow's shared actions/menus via `setNciQuickMenu`/`setQuickAccess`, called at the end of `createMenus()`.
- ✅ **Mode switch Explore / Compute / Teaching** (`MainWindow::createModeBar`/`setAppMode`, UX stage 4b): segmented buttons in the **menu-bar corner** (`setCornerWidget`, TopRight, immune to toolbar reflow), also View ▸ Mode and the palette. The only layout switch; the former layout presets are gone, custom layouts are workspaces. Details in `docks/CLAUDE.md`.
- ✅ **Command palette** (`widgets/commandpalette.*`; Ctrl+K or View ▸ Command Palette): searchable popup that auto-collects every menu action (recursive `menuBar()` walk: title + menu-path + shortcut + `QAction::trigger`); the same harvest feeds Help ▸ Keyboard Shortcuts (`collectMenuBarCommands`).
- ✅ **Menus (UX stage 5)**: File · Edit · View · Structure · Simulation · Tools · Help, every entry a QAction (palette + shortcut list). Edit ▸ Preferences = former Settings menu; View = mode radio, quick toggles, Style ▸ (keys 1–4 + sizes), Look ▸, camera (Fit, Center, Views ▸), Panels ▸; Structure = tool radio View/Measure `M`/Edit Ctrl+E/Build `B`, Add Molecule/Hydrogens, Move to Origin, RMSD; Simulation ▸ Start MD/Optimization really start (`onStartClicked`, disabled while running), Stop, Parameters/Snapshots/Charts; Tools = Run Calculation Ctrl+R/F5, New Calculation Directory Ctrl+N, Clear Output Ctrl+L, NMR Spectra, Configure Programs.
- ✅ **Viewport context menu** (`showViewportContextMenu`): on an atom the atom actions; on empty space Fit, Center, NCI/H-bond toggles, Hydrogens ▸, Hide Molecules ▸, Style ▸, Look ▸, Deselect, Quick Photo (shared QActions/QMenus).
