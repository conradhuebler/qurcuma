# NCI overlay

Detail moved from `src/CLAUDE.md` (Oct 2026), text unchanged. Statements about code were not re-checked during the move.

- ✅ **Geometrische Erkennung** (`ncianalysis.{h,cpp}`, `namespace nci`, freie Funktionen, keine Klasse): H-Brücken (2.50 Å H···A / 130° D-H···A), Halogenbrücken (0.95·Σr_vdW / 150°, F ausgeschlossen), π-Stacking (planare 5-/6-Ringe, Zentroid ≤ 5.5 Å, parallel ≤ 30° + Versatz ≤ 2.0 Å oder T-förmig ≥ 60°), vdW-Nahkontakte (0.90·Σr_vdW, default aus). Literaturstellen stehen als Doxygen-Kommentar an `detectGeometric()`.
- **Radien**: `nci::vdwRadius()` nutzt curcumas `Elements::VanDerWaalsRadius` — **nicht** `elem::vdwRadius()`, das ist ein Zeichenradius (H = 0.5 Å, 16 Elemente).
- **Ringe**: curcumas header-only `Topology::FindRings` (maxsize 8), nur bei Topologieänderung; Cache `m_nciRings` im Viewer, invalidiert bei jedem `fullRebuild` und bei dynamischer Bindungsänderung.
- **Datentypen** in `ncitypes.h` (ohne `view.h`), damit `view.h` `nci::Options`/`nci::Result` als Member halten kann; `ncianalysis.h` zieht beide zusammen.
- **Overlay**: `SceneController::setNciContacts` → `rebuildNci()` baut gestrichelte Linien aus kurzen `#Cylinder`-Segmenten (kein Dash-Primitive in Quick3D), Alpha in die Instanzfarbe eingebacken + `alphaMode: Blend` im QML (dieselbe Falle wie beim Wall). Model unter `moleculeRoot`; Beschriftung über eine zweite `QVariantList nciLabels` mit dem kopierten `Text`-Delegate.
- **Einstieg pro Frame**: `MoleculeViewer::refreshNciOverlay()` hängt am Ende von `syncSceneToController()` (deckt Frame-Wechsel, Live-MD, Edit, Refresh ab) plus `finalizeEdit()`.
- **Berechnete Quellen**: `ncianalysisworker.{h,cpp}` auf eigenem Thread (der Sim-Thread ist vom MD-Timer belegt). GFN-FF liefert eine **Kandidaten**-Enumeration (>5000 Tripel bei 114 Atomen) — `applyGeometricGate()` reduziert sie auf die im Frame eingegangenen Terme. Pro-Kontakt-Energien für HB/XB existieren in GFN-FF nicht; Coulomb und D4-Dispersion dagegen sind aus den Parametern geschlossen berechenbar.
- **Live-MD** (Opt-in): `SimulationWorker::setLiveNci` setzt `hb_update_force_every=1` und legt die HB/XB-Listen in `SimulationFrame::nciContacts`.
- **Farben frei wählbar**: `nci::Palette` (`QHash<int,QColor>`, Schlüssel = `nci::paletteKey()`; Elektrostatik ist nach Vorzeichen in zwei Schlüssel getrennt) liegt im Viewer, wird von `pushNciToScene()` und der Kontakttabelle gelesen. Bead-Typ-Farben als `QHash<QString,QColor>` in `SceneController` (`typeColor()` prüft erst den Override). Beide persistiert in eigenen QSettings-Gruppen (`visualization/beadColors`, `visualization/nciColors`), beide in `cloneStateFrom` mitkopiert.
- **Fragment-Einfärbung (Wirt-Gast)**: `SceneController::ensureFragments()` bildet die Zusammenhangskomponenten des Bindungsgraphen, sortiert **nach Atomzahl absteigend** (Fragment 0 = größtes = Wirt, bleibt ungetönt) und baut je Fragment die Hill-Summenformel. `applyFragmentTint()` verschiebt über `tintFragmentColor()` nur den Farbton (Sättigungsboden für Grautöne, kein Abdunkeln) mit einstellbarer Stärke; `schemeColorFor(index)` ist der indexbasierte Einstieg, den Atome und Bindungshälften nutzen. Faul berechnet, `m_fragmentsDirty` bei `setStructure`/`updateBonds`/`clear`. `atomDrawRadiusFor(index)` multipliziert zusätzlich `fragmentScaleFor()` auf den Zeichenradius; wirkt auf Atome, Bindungsdicke und die Endpunktkürzung der NCI-Striche. Farbe, Tönungsstärke und Größe sind je Fragment überschreibbar (`m_fragmentColors`/`m_fragmentStrengths`/`m_fragmentScales`) über einem gemeinsamen Vorgabewert; `clearFragmentOverrides()` setzt alle drei zusammen zurück. **Bedienmodell**: die Combobox im Display-Panel wählt das Fragment, der Kasten darunter trägt dessen Namen im Titel und wirkt ausschließlich darauf - kein global wirkender Regler daneben. Persistiert als `fragmentTint`/`fragmentTintStrength`/`fragmentScale` in `DisplaySettings`; die Farbüberschreibungen pro Fragment sind strukturspezifisch und werden bewusst **nicht** gespeichert. Test: `test_fragments`.
- **Bead-Typ-Liste**: `SceneController::beadTypes()` zählt die `type`-Labels der aktuellen Struktur (alphabetisch, mit Anzahl) — das Display-Panel baut sein Auswahlfeld daraus, statt aus einer festen Tabelle. `MoleculeViewer::beadTypesChanged()` feuert bei jedem `fullRebuild`.
- Tests: `test_nci` (Kriterien), `test_nci_gfnff` (curcuma-Pfad, braucht `release/conf_28.xyz`).
