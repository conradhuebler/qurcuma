# 3D viewer, SceneController, display

Detail moved from `src/CLAUDE.md` (Oct 2026), text unchanged. Statements about code were not re-checked during the move.

- ✅ **Renderer = Qt Quick 3D on the Vulkan RHI** (migrated off Qt3D, which is fully removed). `MoleculeViewer` (`view.*`) stays a `QWidget` with its public API unchanged, but internally wraps a `QQuickWidget` (composited like a normal widget, so docks/menus can overlap it; `QURCUMA_NATIVE_VIEWPORT=1` = old `QQuickView`/`createWindowContainer` route) + `SceneController` view-model (`scenecontroller.*`) + `src/qml/viewer3d.qml`. Atoms/bonds = `QQuick3DInstancing` (`atominstancing.*`/`bondinstancing.*`); effects via `ExtendedSceneEnvironment` (SSAO/Bloom/HDR/Tonemap/Fog) + world-fixed cast shadows.
- **Performance roadmap** — `docs/WP-performance.md` (P0 measure → P3 latest-wins frames → P1 bonds in worker + cell list → P2 position-only instancing → P5 adaptive GPU quality → P4 NCI/collisions off-thread; render thread parked). P0 (coarse GUI-side bond/rebuild timing, `MoleculeViewer::setPerformanceAnalysis`) and P3 (frame coalescing, `MoleculeViewer::onWorkerFrameReady`) are ADDED. **ADD** remaining: P1 bonds in worker + cell list still O(N²) `detectBondsHysteresis` on the GUI thread every MD step, then P2/P5/P4.
- Vulkan chosen in `main.cpp` via a probe (`QVulkanInstance::create()`) with OpenGL fallback; override `QSG_RHI_BACKEND`. In this Qt build `QQuick3DViewport`/`Camera` are PRIVATE headers → the camera is axis-aligned and C++ replicates its projection for picking/grab (no private headers). The molecule rotates under `moleculeRoot`; the camera stays fixed. [[quick3d-private-headers]]
- Rendering modes (ball-stick/space-filling/wireframe/sticks), color schemes (CPK/mono/by-charge/**by-type** for CG beads → `SceneController::typeColor`, deterministic hue per type label), per-atom draw radius (`atomDrawRadius`: bead radius override or element vdW), transparency, atom/bond size — all in `SceneController`. `schemeColor(AtomDatum)` is the single colour source for atoms **and** bonds **and** overlays. RMSD overlays = a **list** of aligned structures (`m_overlays`) packed into the two overlay instancing buffers by `rebuildOverlays()`; each **inherits the global display styles** (mode/scale/bond/transparency/base scheme) and adds a per-structure colour **tint** (`shiftOverlayColor(base,tint)`, hue/sat shift over `schemeColor`, element identity kept) + **size**. `rebuildGeometry()` calls `rebuildOverlays()` so style changes propagate; API = `addOverlayStructure`/`setOverlayTint`/`setOverlaySize`/`setOverlayVisible`/`removeOverlayStructure`/`clearOverlay`. `setPrimaryVisible(bool)` hides/shows the primary (reference) structure (RMSD workspace).
- ✅ **Per-atom overlay labels** (Appearance ▸ Style ▸ "Labels": Element/Type/Index + "selected only"; also View ▸ Atom Labels): `SceneController::rebuildLabels()` builds a `QVariantList` of `{px,py,pz (local), text}` (rebuilt on structure/selection/live-frame/mode change only); `viewer3d.qml` `Repeater` **projects each to screen reactively** (mirrors the C++ axis-aligned camera: quaternion-rotate local−center by `rootRotation`, camera at `pivotPosition+(0,0,cameraDistance)`), so rotation/zoom/pan need no C++ recompute. Element mode falls back to bead `type` when there is no element.
- ✅ **Hydrogen display** (View ▸ Hydrogens, key `H` cycles; visual only): All / Polar (skeletal-formula convention: an H bonded only to C is hidden) / None. Rule = `SceneController::computeHydrogenMask` (tested in `test_fragments`); hidden atoms are not drawn, labelled or pickable, their bonds are skipped, an NCI line starts at the H's bonded atom; overlays follow. Build mode always shows all H (`MoleculeViewer::pushHydrogenDisplayToScene`). Persisted as `hydrogenDisplay` in `DisplaySettings`.
- **ADD (zu klären): Charge source for "By Charge"** — today charges only arrive as a side product of the GFN-FF/GFN2 NCI analysis (`NciAnalysisWorker` → `chargesReady` → `setAtomCharges`, current frame only). Options: request GFN-FF EEQ charges directly, or take partial charges from calculations/files; live MD open.
- ✅ **Hide molecules by kind** (View ▸ Hide Molecules, bar button next to H; display only): fragments grouped by formula (`SceneController::moleculeKinds`, most numerous first), hidden through the same mask as the H display (`isAtomHidden`); NCI contacts to a hidden molecule are dropped, pi-stacking included (`NciSegment::ownerA/ownerB` = a ring atom); RMSD overlays hide their own molecules of the same kinds (`computeMoleculeKindMask`, pure, like `computeFragments`). The viewer owns the choice (`MoleculeViewer::setHiddenMoleculeKinds`), resets it in `setTrajectoryData` and ignores it in Build mode; not persisted. Tested in `test_fragments`.
- ✅ **Looks** (`src/look.h`, UX stage 3): a look = colour scheme, material, fog, SSAO, bloom, HDR/exposure, corner lights, background, and nothing else. `MoleculeViewer::applyLook` calls only those setters, so a look can never switch a quick toggle (NCI, H display, hidden molecules, labels, render style). Built-ins in code (`looks::builtIn`: Default, Publication, Presentation, Flat (Teaching)); user looks as one JSON array (`Settings::userLooks/saveUserLook/deleteUserLook`). One menu (`MainWindow::populateLookMenu`, rebuilt on open) serves the bar's Look ▾, View ▸ Look, the context menu and the palette; the export dialog picks View (camera) and Look separately and stores both names in the PNG. The pre-2026-09 display presets were dropped once (`dropLegacyDisplayPresetsOnce`, operator decision).
- ✅ **Last session is restored**: `MainWindow::closeEvent` saves `currentDisplaySettings()` (incl. background, corner lights, fog distance), `setupUI` applies it at startup; Save/Load Defaults are gone, the panel keeps only "Reset to Factory Settings". NCI option changes emit `nciOptionsChanged` (Hydrogen Bonds quick toggle `Shift+N` ↔ panel checkbox).
- ✅ **Screen-fixed corner lights** (◤◥◣◢): `DirectionalLight`s parented to the QML camera (lit zone stays view-fixed); a separate world-fixed key light casts shadows. Toggled via `SceneController` cornerLight properties.
- ✅ **Image export** (File ▸ Export Image…, Ctrl+Shift+E → `MoleculeViewer::exportImageDialog`/`exportImage`): true high-res **offscreen render via `QQuickRenderControl` + `QRhi`** (needs `Qt6::GuiPrivate`, `#include <rhi/qrhi.h>`) — render the QML scene to a `QRhiTexture` at the chosen resolution and read it back. `grabWindow()` on a hidden window returns blank (threaded render loop), so the render control drives rendering synchronously. Uses a **separate** `SceneController` (`cloneStateFrom`, no scene-graph node sharing) and reuses the live view's `QVulkanInstance` for the Vulkan backend; OpenGL needs `result.mirrored()` (`rhi->isYUpInFramebuffer()`). Dialog: width/height (default 2× viewport), background (transparent default/white/scene), SSAA toggle; default folder = current workspace. Export-only `SceneController` props `highQualityAA` (SSAA VeryHigh) + `transparentBackground` bound in `viewer3d.qml`; transient overlays (selection/measurement/force vectors) are not cloned → clean image.
