# Lessons (OER teaching scenarios)

Detail moved from `src/CLAUDE.md` (Oct 2026), text unchanged. Statements about code were not re-checked during the move.

- ✅ **Lesson v1** (`src/lesson.*`, `src/dialogs/lessonmetadatadialog.*`) — self-contained `*.qlesson.json` bündelt mehrere Strukturen (inline XYZ) + je volle `SimulationConfig` + Metadaten (Titel/Lizenz/Keywords + Autoren mit ORCID/Einrichtung). `simConfigToJson`/`simConfigFromJson` = einziger verlustfreier `SimulationConfig`-Roundtrip (eigene Feldnamen, entkoppelt von curcumas `simplemd`-Param-Schema). `extractLesson()` entpackt beim Laden nach `<file-dir>/<stem>/` als `<slug>.xyz` + Sidecar `lesson.json` (mit `file`-Verweisen) → Strukturen im bestehenden Datei-Browser.
- ✅ **File ▸ Lesson-Menü** — `openLesson` (laden→entpacken→`switchWorkingDirectory`), `addCurrentStructureToLesson` (dialogfrei: fügt mit Default-Namen hinzu, selektiert + fokussiert den Inline-Detail-Editor), `editLessonMetadata`, **`Save Lesson`** (überschreibt direkt die gemerkte `m_lessonFilePath`) / **`Save Lesson As…`** über `saveLessonInteractive(forceDialog)`. Klick auf eine **extrahierte** `.xyz` → `applyLessonConditions()` (Hook am Ende von `loadMoleculeFile`) liest das `lesson.json`-Sidecar und ruft `SimulationControlWidget::applyConfig()` (Umkehrung von `buildConfig`, signal-blockiert) → Bedingungen wiederhergestellt.
- ✅ **Lesson-Abschnitt oben im Project-Panel** (`ProjectDock::lessonSection`, `CollapsibleSection` „Lesson (N)“): Metadaten (Titel/Beschreibung inline + „Authors/License…“ → `LessonMetadataDialog`), eigene Strukturliste (`LessonStructureModel`, `LessonController::setLessonView`; Klick lädt, Kontextmenü Load/Remove) und Detail-Editor (Name/Notes/Role, schreibt in `m_lesson.structures[row]`). Sichtbar in Teaching (offen, als erstes Element) und sobald die Lesson Strukturen hat; der Datei-Browser darunter zeigt in jedem Modus Dateien. Zähler/Öffnen über `structureCountChanged`/`revealRequested`.
- ✅ **Aus dem Datei-Browser hinzufügen** — Kontextmenü „Add to Lesson" auf xyz/vtf/pdb/mol2 **und** Drag&Drop von Dateien auf den Lesson-Abschnitt (`setAcceptDrops`, Drop in `MainWindow::eventFilter`). Beide laufen über `LessonController::addFile(s)` → `appendStructureFromAtoms` (lädt die Datei nicht in den Viewer, erhöht nur den Zähler). Mehrfachauswahl/-drop wird in einem Rutsch hinzugefügt.
- ✅ **Panels** — `Lesson::panels` (JSON `layout.panels`, optional, dock objectNames): Save Lesson records the open panels (`DockManager::openPanels`); Open Lesson emits `lessonOpened`, MainWindow switches to Teaching (Edit ▸ Preferences ▸ Open Lessons in Teaching Mode, `ui/lessonOpensTeaching`, default on) and then restores them (`showPanels`, Simulation in front). Only which docks are open, not sizes or positions (portable across screens and dock-layout versions). Test: `test_recipes`.
- „Druck" (Haber-Bosch) = Box-/Wandvolumen (`wall*`) + Zusammensetzung; kein Barostat/NPT. Ergebnis-/Ziel-Felder im Schema reserviert, in v1 nicht implementiert.
