# CellDock and ScriptDock

Full descriptions behind the bullets in `src/docks/CLAUDE.md`.

- `CellDock` — right-side dock (tabified with Structure, hidden until a cif is loaded; View ▸ Panels ▸ Unit Cell): Show = asymmetric unit (default, like Avogadro/Mercury) | unit cell (+ "Complete molecules": molecules cut by the faces reassembled); Disorder = one SHELX PART group (major preselected) | all (overlapping); cell (a/b/c, α/β/γ, volume) + "Show cell in the viewer" (persisted `structure/showCell`); contents (space group, formula (Z), sites, symmetry operations, atoms in asym. unit / unit cell); a/b/c repeats (unit cell only); "Thermal ellipsoids" (shown only with ADPs in the file): toggle + probability %, persisted `structure/ellipsoids`, `structure/ellipsoidProbability`, emits `ellipsoidsChanged`. Every change emits `optionsRequested(CifOptions)` → MainWindow re-reads via `MoleculeFileLoader::load(path, options)`; content/disorder apply at once, repeats on **Apply**. Options reset to the defaults when another file is opened. Drops the file (placeholder page) once the scene's atom count no longer matches the cif.

- `ScriptDock` — bottom dock (tabified with Output, hidden by default): editor, Run (Ctrl+Return) / Stop, worked examples, **Record** (the operator's own tool calls become `tool(...)` lines in the editor; calls from the assistant and from a replay stay out — `ToolDispatcher::callOrigin`), output pane, editor text persisted under `script/editor`. Only what runs through the dispatcher can be recorded: a menu action without a tool does not appear in a macro. Runs the script on its own thread; the value of the last expression is the result. **Not** behind `USE_LLM`. Unlike the assistant's `calculate`, it is given a **tool bridge**, because the operator pressing Run is the permission — but every call still goes through `ToolDispatcher` and `MainWindow::approveToolCall`, which was moved out of the `USE_LLM` block so both consumers share one policy and one set of session grants. Before a run that names a tool doing more than reading or displaying, the dock lists those tools (literal names only, `script::namedToolsIn`).
