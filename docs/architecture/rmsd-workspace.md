# RMSD workspace

Detail moved from `src/CLAUDE.md` (Oct 2026), text unchanged. Statements about code were not re-checked during the move.

- ✅ **RMSD / Align** (`src/rmsdwidget.*`, `RMSDWidget : QWidget`) — RMSD-Tab in der SimulationDock, backed by curcuma `RMSDDriver`. **Workspace = `QTableWidget` von Strukturen** (`m_structures`, jede mit stabiler `id`): Spalten Ref-**Radiobutton** (welche Struktur ist Referenz) · Show-Checkbox · Name · **plain RMSD** (Kabsch best-fit in ursprünglicher Atomreihenfolge, berechnet in Qurcuma) · **perm. RMSD** (`RMSDDriver::RMSD()` nach Reorder) · Farb-Swatch (`QColorDialog`) · Größen-Spinbox · Remove. Genau eine Struktur ist Referenz (= Primary im Viewer); die anderen werden gegen sie ausgerichtet und als getönte Overlays gezeichnet. Radiowechsel → `setReferenceByIndex` → `realignAll`. Die Zeilen-Controls fangen die `id` (nicht Pointer/Index) → robust gegen `rebuildTable()`. Layout logisch: Options-Group (Method default **inertia** · Include hydrogens · Template-Element · Threads) → Tabelle → **eine** Aktionszeile darunter [Add structure… · Use current view as reference | **☐ Reorder atoms** · Re-align all] → Reorder-Mapping-Detail. Reorder-Checkbox **default aus** (Permutationssuche ist teuer); an → `force_reorder=true`/`no_reorder=false` (curcuma reordert sonst nur bei abweichender Atomreihenfolge → Methode allein würde Konformere in gleicher Reihenfolge nicht permutieren), aus → `no_reorder=true` (perm.-Spalte „–"). Buttons: „Use current view as reference" (`seedReferenceRequested` → `MainWindow::seedRMSDReference` → `setReferenceStructure`), „Add structure…" (`addStructureFromFile`), „Re-align all" (mit aktuellen Options). Viewer-Anbindung entkoppelt über Signale: `overlayWorkspaceChanged(ref, refVisible, refTint, overlays, resetView)` (Voll-Rebuild → `MoleculeViewer::setOverlayWorkspace`; `resetView` nur bei Referenzwechsel, sonst kein Kamerasprung) + günstige `overlayTint/Size/VisibilityChanged`(index)/`referenceVisibilityChanged`(→`setPrimaryVisible`)/`referenceTintChanged`(→`setPrimaryTint`). **Farbe ist stabil pro Struktur, nicht pro Rolle** (Claude Generated 2026): jede Struktur bekommt beim Anlegen einmalig eine Farbe aus der gemeinsamen Palette (`nextDefaultTint`), auch die, die sofort Referenz ist — `SceneController::setPrimaryTint`/`schemeColorFor` wendet dasselbe `shiftOverlayColor` auf die Primärstruktur an, das sonst Overlays einfärbt, sodass eine Struktur beim Referenzwechsel ihre Farbe behält statt auf das globale Farbschema zu wechseln. Ändert sich eine Farbe nur noch über den Swatch-Klick. Kontextmenü „Overlay onto current (RMSD/Align)…" → `showRMSDTool` → seedet Referenz nur falls keine vorhanden + `addStructureFromFile` → `structureAligned` → Statusbar-Feedback. `addStructure` macht einen **Dubletten-Check** über den Namen (`isDuplicateName`, case-insensitiv) → dieselbe Datei wird nicht doppelt aufgenommen. `loadMoleculeFile` ruft `clearWorkspace()`.
